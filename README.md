# 회의 콘솔 설치 안내

회의를 자동으로 녹음하고, 음성을 글로 옮기고, 회의 노트 초안까지 만드는 도구다. 맥 한 대에 각자 설치한다.

**오디오와 회의 내용은 그 맥을 떠나지 않는다.** 녹음·STT·화자 분리·초안 생성이 전부 로컬에서 돈다. 콘솔 서버는 `127.0.0.1` 에만 붙고 토큰이 없으면 응답하지 않는다.

**캘린더는 ICS(iCal) 주소를 주는 서비스면 된다.** 구글 캘린더로 검증했고, Outlook·iCloud·네이버는 설치 마법사에 주소 찾는 법을 적어 두었다.

**녹음 전에 참석자 동의를 받는다.** 마이크만 녹음되므로 온라인 회의 상대방 목소리는 담기지 않는다.

---

## 받기

```
git clone <이 레포 주소> meeting-console-bundle
cd meeting-console-bundle
```

레포 주소는 이 페이지 상단의 클론 주소를 그대로 쓴다.

## 설치

```
./install.sh --check     # 사전 점검만
./install.sh             # 설치
```

`install.sh` 가 하는 것: 사전 점검(macOS 13+ · Apple Silicon · 디스크 3GB) → 없는 도구 설치(ffmpeg · uv) → 모델 내려받기(약 1.7GB) → 녹음기 컴파일 → launchd 등록 → 웹 마법사 열기.

Homebrew 와 Xcode Command Line Tools 는 관리자 비밀번호를 물어서 자동으로 설치하지 않는다. 없으면 명령을 알려주고 멈춘다.

## 마법사 7단계

브라우저에서 이어서 한다. 각 단계는 통과·미통과·건너뜀으로 표시되고, **브라우저를 닫아도 통과한 단계는 남는다** (`meeting-console/.state/setup.json`).

1. **시작**: 무엇을 설치하는지, 걸리는 시간, 디스크 사용량, 회의 내용이 밖으로 나가지 않는다는 고지, 참석자 동의 고지
2. **시스템 점검**: macOS · 칩 · 디스크 · brew · ffmpeg · uv · swiftc · claude. 미통과 항목에는 해결 명령이 붙는다. Apple Silicon 이 아니면 여기서 막힌다
3. **도구 설치**: 없는 것만 설치하고 로그를 흘린다
4. **모델 내려받기**: whisper large-v3-turbo(약 1.6GB)와 화자 분리 모델(약 45MB). 이미 있으면 건너뜀
5. **마이크 권한**: 3초 녹음을 실제로 해서 판정한다. 길이 2.5초 이상, 평균 음량 -60dB 초과. 포그라운드(콘솔을 띄운 앱)와 launchd 두 경로를 각각 본다. 자동 녹음은 launchd 경로로 돌기 때문에 그쪽이 통과해야 설치가 끝난 것이다. 실패하면 시스템 설정 딥링크가 뜬다. 판정에 쓴 녹음 파일과 임시 plist 는 바로 지운다
6. **캘린더 연결**: 구글 캘린더의 비공개 iCal 주소를 넣는다. 받아서 확인한 뒤에만 저장하고, 오늘 일정과 녹음 대상 표시를 보여준다. **주소는 화면·로그·서버 응답 어디에도 다시 나오지 않는다**
7. **완료**: launchd 등록 상태, 다음 녹음 예정, 메뉴바 앱 띄우기. **메뉴바 앱을 로그인 항목으로 자동 등록하지 않는다.** 등록할지 여기서 고른다. 등록하지 않아도 콘솔은 그대로 동작한다

## 녹음 규칙

- **회의실(LOCATION)이 잡힌 일정만 녹음한다.** 개인 일정·1:1 메모가 자동으로 녹음되지 않게 하는 기준이다
- 제목에 `[녹음]` 을 넣으면 회의실이 없어도 녹음한다
- 노트북 뚜껑을 닫으면 맥이 잠들어 녹음이 끊긴다. 회의 중에는 열어 둔다

## 폴더 구조

```
meeting-console-bundle/
  install.sh
  scripts/            녹음 · STT · 화자 분리 · 캘린더 감시
  meeting-console/    콘솔 서버 · 워처 · 메뉴바 앱
  docs/meetings/      회의 폴더가 여기 생긴다
  .claude/            노트 양식 · /meeting 명령
```

회의 폴더 이름이 `docs/meetings/` 인 이유: 녹음·STT·초안·노트 스크립트가 전부 이 경로를 공유한다. 이름을 바꾸면 경로 가정이 여러 군데서 함께 흔들린다. 이 레포를 쓰지 않는 사람에게는 어색한 이름이지만 그대로 둔다.

## 쓰는 법

- 메뉴바 아이콘: 녹음 상태 · 다음 녹음 대상 · 검수 대기 건수. 「콘솔 열기」로 웹 콘솔을 띄운다
- 콘솔 첫 화면은 주간 캘린더다. 일정을 누르면 그 회의의 검수 화면이 열린다
- **초안까지가 기계 몫이고 확정은 사람 몫이다.** 자동 확정·자동 삭제·외부 전송을 하지 않는다

## 문제가 생기면

| 증상 | 볼 곳 |
|---|---|
| 녹음이 안 된다 | 마법사 5단계를 다시 돌린다 (`/setup`). 마이크 권한은 앱에 붙어서 터미널 앱을 바꾸면 다시 필요하다 |
| 일정이 안 보인다 | 마법사 6단계에서 ICS 주소를 다시 넣는다 |
| 초안이 안 생긴다 | `claude` 가 설치돼 있고 로그인돼 있는지 본다. 콘솔 제어판의 「진단」에 최근 실패 3건이 나온다 |
| 오디오만 있고 원문이 없다 | STT 가 아직 도는 중이거나 실패한 것이다. 제어판 「처리 상태」에서 확인한다 |

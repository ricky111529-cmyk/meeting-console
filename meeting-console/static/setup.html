회의 콘솔 설치

7단계입니다. 브라우저를 닫아도 통과한 단계는 남습니다.

1. 시작

  • 회의를 자동으로 녹음하고, 음성을 글로 옮기고, 회의 노트 초안까지 만드는 도구를 설치합니다
  • 걸리는 시간은 10~30분입니다 (대부분 모델 내려받기)
  • 디스크를 약 1.7GB 씁니다
  • 오디오와 회의 내용은 이 맥을 떠나지 않습니다. 초안 생성은 로컬에서 도는 Claude Code 가 합니다
  • 녹음 전에 참석자 동의를 받으세요. 마이크만 녹음되고 상대방 목소리는 담기지 않습니다
  • 회의 폴더는 docs/meetings/ 아래에 생깁니다. 이 이름은 녹음·STT·노트 스크립트가 공유하는 경로라 바꾸지 않습니다 (바꾸면 파이프라인 전체의 경로 가정이 흔들립니다)
